# Copilot Instructions

## Project Overview

This is a terminal-based crossword puzzle game built using:
- **Ratatui** (https://ratatui.rs) - Terminal UI framework for building rich TUI applications
- Crossterm backend for terminal handling and keyboard input
- Immutable state management pattern (Elm Architecture)

## Ratatui Guidelines

- Use Ratatui widgets for rendering the UI (Block, Paragraph, List, etc.)
- Implement the `Widget` trait for custom components
- Use `Frame::render_widget` to draw widgets to the terminal
- Handle terminal events (keyboard, mouse) through Crossterm's event system
- Keep rendering logic separate from state logic
- Use layout constraints (Constraint::Percentage, Constraint::Length) for responsive layouts

## Rust Style Guidelines

- Prefer immutable data structures and functional programming patterns
- Avoid mutable state (`mut`) unless absolutely necessary
- Use immutable methods that return new instances rather than modifying in place
- When state changes are needed, take `self` by value and return new instances
- Prefer pattern matching and iterators over loops with mutable variables
- Use ownership transfer (`self`) instead of borrowing (`&self`) for state updates to avoid unnecessary clones

## Example Pattern

Instead of:
```rust
pub fn fill_tile(&mut self, x: usize, y: usize, ch: char) {
    self.grid[y][x] = BoardTile::Filled(ch);
}
```

Prefer (ownership transfer):
```rust
pub fn fill_tile(self, x: usize, y: usize, ch: char) -> Self {
    Board {
        grid: self.grid.set(x, y, BoardTile::Filled(ch)),
        size: self.size,
        pos: self.pos,
    }
}
```

## Ratatui Example

```rust
use ratatui::{
    backend::CrosstermBackend,
    layout::{Constraint, Layout},
    widgets::{Block, Borders, Paragraph},
    Terminal,
};

// Rendering function
fn render_board(frame: &mut Frame, board: &Board, area: Rect) {
    let block = Block::default()
        .title("Crossword")
        .borders(Borders::ALL);
    
    let paragraph = Paragraph::new(format!("{}", board))
        .block(block);
    
    frame.render_widget(paragraph, area);
}
```
